# Paradise Nursery Shopping Application

Paradise Nursery is a dynamic e-commerce web application built with React and Redux Toolkit. It allows users to browse a curated collection of houseplants, view plant details (image, name, description, price), add plants to a shopping cart, and manage cart items with live-updating quantities and totals.

## Features
- Landing page with company branding and a "Get Started" button
- Product listing grouped into categories (Indoor, Outdoor, Succulents)
- Add to Cart with button disable after adding
- Live cart icon count in the navbar
- Shopping cart page with quantity controls, item removal, totals, and a checkout button
- Redux Toolkit for state management

## Tech Stack
- React
- Redux Toolkit & React-Redux
- React Router
- CSS
